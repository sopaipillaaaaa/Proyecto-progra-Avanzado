# Proyecto-progra-Avanzado
README
Proyecto del curso EL4203 – Programación Avanzada

simulador de red capaz de realizar dos tareas fundamentales: 1. Despacho Económico: Decidir qué generadores encender basándose en sus
costos marginales para satisfacer una demanda dada. 2. Flujo de Potencia (Simplificado DC): Estructurar topológicamente la red para ensamblar la Matriz de Admitancia
Nodal (Ybus) y resolver analíticamente los voltajes de cada barra del sistema ante distintas
inyecciones de corriente.



Para ejecutar el programa:
python clases.py

Python 3.x
NumPy
